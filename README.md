# Rock Paper Scissors 🪨📄✂️
 
A simple Rock Paper Scissors game you play against the computer, built with JavaScript as part of [The Odin Project](https://www.theodinproject.com/lessons/foundations-rock-paper-scissors).
 
## 🎮 Live Demo
 
**[Play here](https://faizaumatiya.github.io/Rock-Paper-Scissor---The-odin-project/)**
 
> The game runs in the browser console. Open the link, press **F12** (or right-click → **Inspect**), go to the **Console** tab, then refresh the page to start.
 
## How It Works
 
- You type rock, paper, or scissors
- The computer picks at random
- The winner of each round gets a point
- After all rounds, the game announces the final winner

## Built With
 
- HTML
- JavaScript
